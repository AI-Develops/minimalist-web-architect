# Minimalist Web Architect

An AI-driven workflow for generating professional landing pages using raw
technologies. This project avoids the "div-soup" and bloat of modern frameworks
in favor of clean, maintainable, and lightning-fast vanilla code.

## 🚀 Features

-   **Framework-Free:** No Tailwind, no Bootstrap. Just pure, modern CSS.
-   **Iconography:** Seamless integration of Heroicons via inline SVGs.
-   **Performance First:** Zero external dependencies, resulting in perfect
    Lighthouse scores.
-   **Responsive:** Mobile-first designs that work on any screen size.

## 🛠️ Tech Stack

-   **HTML5:** Semantic structure for SEO and accessibility.
-   **CSS3:** Modern features like Flexbox, Grid, and Variables.
-   **Heroicons:** Premium SVG icons for a modern look.

## 📋 How to Use

1.  **Copy the Prompt:** Open `Prompt.md` and copy the contents.
2.  **Initialize the AI:** Paste the prompt into your AI assistant (e.g., Gemini
    3 Flash) to set the persona and constraints.
3.  **Provide Requirements:** Tell the AI what kind of landing page you need
    (e.g., "Create a landing page for a boutique coffee shop with a hero
    section, menu, and contact form").
4.  **Review & Save:** Copy the generated code into an `index.html` file and
    open it in your browser.
